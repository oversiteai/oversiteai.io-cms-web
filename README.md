# OverSite AI -- GitHub Pages Deploy Target

This repository is an **auto-deployed GitHub Pages site**. Its contents are
compiled and pushed automatically by CI/CD pipelines -- do not edit files
here directly. Any manual changes will be overwritten on the next deploy.

All source code, content editing, and deployment configuration lives in the
